## VS Code 与烧录任务

外层 `.vscode/tasks.json` 提供环境检查、CMake 配置、编译、全量重新编译、清理、固件大小、ST-Link 烧录和 CMSIS-DAP 烧录，共 8 个任务。外层 `.vscode/settings.json` 设置 CMake 源目录和 C/C++ 编译数据库。

默认构建任务是 `MCU: 编译`，在 VS Code 打开外层 `coating_inspection_mcu` 后按 `Ctrl+Shift+B` 即可执行。烧录任务先编译，再通过 SWD 使用 ELF 写入、校验、复位和退出，默认调试时钟 1000 kHz。

JSON 语法与任务依赖检查通过；本机 OpenOCD 0.12.0 的 ST-Link / CMSIS-DAP 接口、STM32F4 目标配置和编程参数解析均通过。检查时替换了编程动作，没有初始化目标、访问硬件或写入 Flash。

详细操作见 [编译与烧录说明](../STM32F407_FreeRTOS_CMake/CMAKE_BUILD.md)。

## 后续开发与待验收

当前固件仍为 GPIO、UART1/2（115200、8N1）、LED 翻转的基础工程。UART 中断接收以 IDLE 整理缓存，不是项目要求的 RTU 定界；没有环形 DMA、RS485 DE、完整错误恢复、命令身份状态机、任务健康和 IWDG。

原 UART 接口仍有共享缓存、发送容量与并发访问方面的限制。后续工位通信应按交接文档建设有界 DMA / 软件缓冲与统一输出保护，不能直接将基础 UART 接口视为项目通信已完成。

板卡时钟、GPIO 有效电平、任务调度、UART 波特率和实际烧录尚需上板验证。`.ioc` 保留清理后的芯片 / 时钟 / GPIO 参考，手工应用代码的 CubeMX 再生成流程未验证。
