## 协议与诊断冻结（后续实现依据）

- 从站地址 1，115200、8E1，协议版本 0x0200。寄存器字节高位先发，32 位高字在低地址，CRC 低字节先发。
- FC04 输入寄存器 0x0000～0x0015，完整快照 22 字；FC06 仅写 0x0100 心跳；FC10 必须从 0x0110 一次写 9 字 / 18 字节；FC03 仅读心跳单字或命令块连续子区间。
- 广播不执行不响应；队列满异常 0x06，不成功回复后丢命令；实际执行结果经业务 ACK 发布。
- 状态 BOOT=0、IDLE=1、READY=2、INSPECTING=3、COMPLETED=4、FAULT=5。
- 命令 SYNC_SAFE=1、START=2、APPLY_RESULT=3、ACK_INPUT_EVENT=4、RESET_FAULT=5、ABORT=6。
- ACK_STATUS 0 无、1 执行成功、2 状态拒绝、3 token 拒绝、4 epoch/seq 拒绝、5 健康拒绝、6 参数/命令拒绝。
- 输出只允许 0、PASS=1、FAIL=2、FAULT=4；故障覆盖普通结果输出。
- HEALTH_MASK bit0 CommTask、bit1 WorkstationTask、bit2 HealthTask，正常 0x0007；业务检查全部条件。MCU_HEARTBEAT 在健康任务完成正常检查后递增。
- RESET_REASON bit0 上电、bit1 引脚、bit2 软件、bit3 IWDG、bit4 WWDG、bit5 低功耗、bit6 BOR，保留并存原因及原始 RCC_CSR。
- COMM_ERROR_COUNT 为通信/协议错误的 32 位饱和计数。按钮忙碌和业务拒绝独立计数。
- FC03 命令读回最近缓存的已处理命令，包括合法新序号的明确拒绝；同身份不同内容不覆盖缓存。
- 新 SYNC 接受更大非零 epoch，撤销旧 token/结果/事件，清除心跳有效资格但保留数值；同步后必须再有一次心跳变化才能 RESET / START。
- 同身份、同内容重传只回历史结果；条件后来变化不得使之前明确拒绝的重传执行。PASS 成功后故障，历史 ACK 成功不能恢复 PASS。
- 普通命令必须属于当前 epoch，seq 严格前进但不要求加 1；ACK_INPUT_EVENT 精确匹配事件号，不强制匹配任务 token。ABORT 不依赖新鲜心跳，当前 token 非零时须匹配，已清零时允许原任务撤销。
- 故障优先级：内部任务异常 > 接收通道故障 > 检测中离位 > 主站超时 > 主站撤销 > 未同步，另存首故障上下文。SYNC / ABORT 不清内部故障门控；RESET 不绕过未恢复原因。
- 事件号一次启动内不复用，耗尽先关闭结果，再受控复位重新同步。

## 实现参数与测试约束

纯 C 状态机、协议和去抖模块不依赖 HAL/FreeRTOS；时间、输入及健康条件由调用参数提供。应用使用原生 FreeRTOS 三个静态任务和容量 8 的静态命令队列：HealthTask 100 ms / 优先级 5 / 256 words；CommTask 通知唤醒、最长等待 10 ms / 优先级 4 / 768 words；WorkstationTask 10 ms / 优先级 3 / 512 words。栈余量后续实测。

新增使用 FromISR API 的 IRQ 初设优先级 6，最大系统调用 IRQ 优先级为 5。短临界区提交状态和 GPIO，临界区外编码和发送；健康故障门控必须在普通输出提交时再次检查。通信循环预算与让出机制保证工位任务获得运行机会。

输入 10 ms 采样、稳定满 30 ms 才更新；按钮按下沿产生一个锁存事件。ACK 清事件后，须完成包含对应成功 ACK 与空事件的完整 FC04 发送，并经过 1200 ms、两个按钮稳定释放，才重新开放；保持期按键丢弃并计数，不缓存。部分快照不能开放按钮。

RX DMA 512 B、软件 RX 缓冲 1024 B，普通 SRAM；最大 RTU ADU 256 B，t1.5 / t3.5 初值 750 / 1750 μs，接收间隔在 ISR / 微秒层保留，不能用任务取数据时间替代。DMA 完成后还须等待 USART TC 才释放 DE。偶校验采用 STM32F4 的 9 位字长以保留 8 个数据位，M2 实测确认。

主站心跳仅变化续期，初值超时 1500 ms；保护撤销输出目标从最后变化被接受起不超过 1700 ms。Comm / Health 进度期限 300 ms，Work 100 ms；只有任务正常完成循环才能报进度。外部主站离线而内部健康时继续喂狗。IWDG 初值预分频 32 / reload 2999，实际期限须结合 LSI 及上板实测。

测试按用户计划覆盖黄金向量、四功能码与非法请求、队列满、分段跨界与重同步、epoch/seq/token 幂等和拒绝、完整正常闭环、离位与恢复、按钮重新开放、心跳/毫秒回绕、任务停滞、故障后历史 PASS 重传。主机测试不代替 GPIO/DMA/串口波形和实机 24 h 证据。

最终产物包含 ELF/BIN/HEX/MAP、版本与哈希、接线/IRQ/DMA/时钟配置、寄存器与诊断说明、测试、实机日志、波形和演示记录。MCU 不接 BLE/OneNET、不保存厚度规则、不累计测点；真实 BLE 仪器通过既有上位机联调。
